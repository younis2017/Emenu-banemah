# 🍽️ Ban3mah Digital eMenu

A modern digital menu solution for **Ban3mah Restaurants**, designed to provide customers with an easy, fast, and mobile-friendly way to explore restaurant branches, food categories, menu items, prices, calories, allergens, and available ordering channels.

## 📌 Overview

Ban3mah Digital eMenu is a web-based restaurant menu experience built to replace traditional printed menus with an interactive digital solution.

Customers can browse the menu by category, view item details, prices, nutritional information, and food images, and access available ordering platforms.

The solution supports a **multi-branch restaurant environment**, allowing each branch to have its own menu configuration.

Ban3mah has a long-standing restaurant history dating back to **1952**, with its roots in Makkah and traditional Hijazi cuisine. The company currently operates multiple branches and offers a wide range of traditional dishes.

## ✨ Features

### 📱 Digital Menu

- Mobile-friendly restaurant menu
- Fast category navigation
- Food images
- Item descriptions
- Saudi Riyal pricing
- Calories / nutritional information
- Allergen information
- Featured food items

### 🍽️ Menu Categories

Examples of available categories include:

- فول
- قلابة
- مطبق مالح
- مطبق حلو
- بيض وشكشوكة
- التميس
- معصوب وفتة
- أطباق شعبية
- التعتيمة
- خاص بانعمه
- سندوتشات بانعمه
- مشروبات باردة
- مشروبات ساخنة
- الوجبات

### 🏢 Multi-Branch Support

The menu supports branch-specific experiences.

A branch can be identified using a unique branch identifier, allowing the same digital menu platform to serve multiple restaurant locations.

### 📊 Food Information

Each menu item can contain:

- Item name
- Description
- Price
- Calories
- Estimated nutritional information
- Food image
- Category
- Special indicators

### 🚚 Ordering Integration

The restaurant provides access to external food delivery platforms, including:

- Jahez
- HungerStation
- Keeta
- Marsool
- Ninja
